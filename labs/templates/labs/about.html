STREETHOUSE PROJECT

Про проект STREETHOUSE

STREETHOUSE — це навчальний Django-проєкт інтернет-магазину вуличного одягу. На сайті реалізовано каталог товарів, категорії, кошик, замовлення, реєстрацію користувачів, особистий кабінет, оцінки товарів та підписку на розсилку.

Що реалізовано на сайті

🛍️

Каталог товарів

Товари розподілені за категоріями. Користувач може переглядати товари, відкривати детальну сторінку та вибирати розмір.

🛒

Кошик

Реалізовано додавання товарів у кошик, вибір розміру, кількості та оформлення замовлення.

👤

Особистий кабінет

Користувач бачить тільки свої замовлення, а адміністратор має доступ до всіх замовлень магазину.

⭐

Оцінка товарів

На сторінці товару можна поставити оцінку, а також переглянути середній бал товару.

📩

Розсилка

У футері сайту є форма підписки на інформаційні листи про нові дропи та акції.

🔐

Авторизація

Реалізовано реєстрацію, вхід, вихід та відновлення пароля через тимчасовий код.

Технології

На чому створено проект

Django Python SQLite HTML CSS Django Admin Sessions Authentication

Ідея проекту

Мета STREETHOUSE — показати, як за допомогою Django можна створити повноцінний сайт інтернет-магазину: від моделей бази даних і адмін-панелі до кошика, замовлень та особистого кабінету користувача.
